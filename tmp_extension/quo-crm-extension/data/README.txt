FULL U.S. NPA-NXX DATABASE
Generated from the uploaded NANPA CoCodeAssignment Utilized All States Public dataset.
Lookup key: first 6 digits of a normalized 10-digit NANP phone number (NPA+NXX).
Displayed area: NANPA RateCenter + State.
Note: this is the number's assigned telephone rate center, not guaranteed current caller location.

Area lookup behavior updated:
- Exact 6-digit NPA-NXX lookup only.
- Bundled prefixes are limited to NANPA records with Use=AS and InService=Yes.
- Result is displayed on one line as: Area, Full State Name (example: Miami, Florida).
- No 3-digit area-code guess is shown when an exact active prefix is unavailable.
